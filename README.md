# The Blade & Fade Unisex Salon — Website

Static 6-page responsive website built for the Digital Marketing (MCC1855) Self Study Assessment I.

## Structure
- index.html — Home
- about.html — About Us
- services.html — Products/Services (price list)
- gallery.html — Gallery
- blog.html — Blog/News (3 original articles)
- contact.html — Contact Us (form + Google Maps embed)
- css/style.css — shared stylesheet
- js/script.js — mobile nav toggle + contact form validation
- SEO_Report.md — on-page SEO techniques implemented

## Deploy
Drag this folder into Netlify, or push to a GitHub repo and enable GitHub Pages
(Settings → Pages → Deploy from branch → root). No build step required — pure
static HTML/CSS/JS.
